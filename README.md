# 이미지 뷰어

Mac용 이미지 뷰어예요. 폴더를 고르면 하위 폴더까지 모두 불러오고, 폴더 여러 개를 한 번에 열 수 있어요.

## 설치

1. GitHub 저장소의 **Actions** 탭에서 가장 최근의 "Build macOS app" 실행을 열어요.
2. 아래쪽 **Artifacts**에서 `ImageViewer-dmg`를 내려받아 압축을 풀어요.
3. `ImageViewer.dmg`를 열고 앱을 **Applications** 폴더로 끌어다 놓아요.
4. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면, **시스템 설정 > 개인정보 보호 및 보안** 맨 아래에서 **그래도 열기**를 눌러요.
   (Apple 공증을 받지 않은 개인용 앱이라서 한 번만 이렇게 허용해 주면 돼요.)

## 사용법

| 동작 | 키 |
| --- | --- |
| 폴더 열기 (여러 개 선택 가능) | ⌘O, 또는 창에 폴더 끌어다 놓기 |
| 다음 / 이전 파일 | → / ←, 스페이스, ↓ / ↑ |
| 처음 / 마지막 파일 | Home / End |
| 확대 / 축소 | + / -, 트랙패드 핀치 |
| 화면에 맞추기 / 실제 크기 | 0 / 1, 이미지 더블클릭 |
| 전체화면 (이미지만 보임) | F (나가기는 Esc) |
| 창 안에서 이미지만 보기 | H 또는 Tab (나가기는 Esc) |
| Finder에서 보기 | 아래쪽 경로를 더블클릭 |
| 썸네일 / 한 장씩 보기 | Return / Esc, ⌘G |
| 폴더 추가 / 목록에서 빼기 | ⇧⌘O, 왼쪽 아래 + / - |
| 상위 폴더로 (폴더별 보기) | ⌘↑, Delete |

**보는 방식**
- 폴더별: 한 폴더씩 들어가며 봐요. 하위 폴더는 폴더 썸네일로 보이고, 더블클릭하면 들어가요. 지금 보는 폴더만 읽어서 빨라요.
- 전체 모아보기: 고른 폴더와 모든 하위 폴더의 사진을 한꺼번에 봐요. 찾는 대로 바로 보여줘요.
- 왼쪽 목록에서 ⌘를 누른 채 여러 폴더를 고르면 자동으로 전체 모아보기가 돼요.
- 선택 모아보기: 폴더나 사진을 ⌘ 클릭하면 계속 골라져요. 다른 폴더로 옮겨 다니며 고른 뒤 위쪽 "선택 모아보기"를 누르면, 고른 사진과 고른 폴더 안의 모든 사진을 모아서 봐요.
- 정렬: 폴더 정렬(이름, 수정한 날짜)과 폴더 안 사진 정렬(이름, 수정한 날짜, 크기)을 따로 고를 수 있어요.
- 필터: 위쪽 검색 칸에 글자를 넣으면 이름에 그 글자가 든 파일만, 형식 필터 메뉴에서 확장자를 고르면 그 형식만 보여요. 폴더별 보기에서 "하위 폴더까지 모아보기"를 누르면 하위 폴더 전체에서 맞는 파일만 모아요.
- 단축키는 한글 입력 상태에서도 동작해요.
- 사진이 아주 많아도 썸네일은 스크롤하는 만큼만 조금씩 만들어요.

연 폴더는 기억해 두었다가 다음에 앱을 켤 때 자동으로 다시 열어요. 목록에서 빼도 실제 폴더와 파일은 지워지지 않아요.

지원 형식: png, jpg, gif(움직임 재생), psd(합쳐진 이미지), clip(Clip Studio 파일에 저장된 미리보기 이미지), mp4/mov/m4v(재생, 스페이스로 재생/정지), bmp, tiff, heic, webp

## 직접 빌드하기

Xcode가 설치된 Mac에서 `./scripts/make-app.sh`를 실행하면 `build/` 폴더에 앱과 dmg가 생겨요.
